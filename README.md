# 💫 About Me

I’m a passionate **Machine Learning** and **Software Engineering** enthusiast who loves turning ideas into real-world, interactive applications. I enjoy working at the intersection of AI, computer vision, and full-stack development, where logic meets creativity.

- 🤖 **Hands-on Experience**: Building intelligent systems using Python, JavaScript, React.js, and modern ML frameworks.
- 🎯 **Focus Areas**: Real-time computer vision (gesture-based controls, emotion detection), LLMs, data automation, and responsive web platforms.
- 💡 **Philosophy**: *Learning by building is the fastest way to grow.*
- 🎯 **Goal**: Becoming a skilled Machine Learning Engineer and contributing to impactful tech solutions that make life easier and smarter.

> 🚀 **Always learning. Always building. Always improving.**
